# daeCrypto

daeCrypto
You will now create your own project, where you use machine learning/AI to solve a predetermined problem.
• Predict the crypto market

Start by describing the problem and what it is you want to accomplish in text. The next step is to try to find data that can help you solve your problem. If you can't get the appropriate data, think again. Can you make a variation on your problem that can be solved with the data you found? If not, define a new problem and try again.
Keep in mind that the data can come from different sources. If you're pulling data from different sources, you'll need to investigate how compatible it is.
Get to know your data.   
• Is it complete?  
• Do you have null values?  
• Do you have extreme values?  
• What data types does the data have?  
• Which fields in your data do you want to use?  
• How can you convert all the fields you want to use into a numeric format?  

#### Type of problem.  
What kind of problem are you trying to solve?  
Is it a classification or regression problem?  
Is your data labeled (i.e. you have ready-made answers to feed your model with during training). If not, how are you going to get it?  
Are you going to create labels yourself or do you want to try to get help from unsupervised learning 
(works well on classification problems but not regression problems).  
Do you want to work with Reinforcement Learning and deep neural networks instead? You get to think about what you want to achieve and what data you want to feed your network with.  
How should it be structured?  
What should your reward/punishment system look like?  
How should you interpret the output you get from the network?  
Which training platform do you want to use to train your network?  

#### Document.  
This is what you should do in step 1.  
In other words, you should not start implementing a solution yet, but investigate the conditions for your project.  
Create a document in which you describe the problem and the solution (according to the questions above) that you came up with.  
If you use datasets, describe the data you found.  
How many rows do you have?  
What's the quality of the data like?  
You will submit this document in your next submission. You can also, if you wish, submit Jupyter 
Notebooks that show how you have examined your data (if you are not going to work with Reinforcement 
Learning).
