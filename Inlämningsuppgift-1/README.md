## The game follows standard Classic Blackjack rules, but with the following exceptions

Dealer draws only one card at the start of the hand, and does not draw more until all player hands are complete.  
Surrender is not allowed.  
Blackjack Pays 1.5% the players bet.  
Player may not re-split (will be implemented later).  
Player can double after splitting(will be implemented later).  
Double Down on 9, 10 and 11 only (will be implemented later).  
Player loses if dealer has blackjack (will be implemented later).  

## How To Play European Blackjack

As you’ll see from the rules above, the major difference between European Blackjack and other variations is that the dealer only gets one initial card.

If the player is dealt a blackjack then it is a winning hand straight away.  
Otherwise, the player gets the option to Hit or Stand as normal.  
The option to Split, Double or Surrender willbe implemented later.

After the players’ hands have been completed, the dealer draws his/her second card.  
Only then do you know for sure if the dealer has Blackjack.
